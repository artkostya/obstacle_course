# Obstacle Course

[English](README.md) | **Русский**

**Obstacle Course** — игра от третьего лица в жанре obstacle course, разработанная на Unreal Engine 5.4.4. Игрок проходит полосу препятствий в каньоне, уворачивается от падающих камней, собирает монеты, перемещается по движущимся платформам и восстанавливает здоровье в лечебных сферах. В смертельной зоне персонаж получает периодический урон.

Проект реализован полностью на **Blueprint** с использованием Unreal Engine 5.4.4. Игровая логика и основные ресурсы находятся в `Content/ObstacleCourse/`.

> **Статус проекта:** версия для выполнения практического задания. Некоторые игровые механики и сценарии завершения забега находятся в планах дальнейшей разработки. См. раздел [TODO](#todo).

## Требования и запуск

### Требования

- Unreal Engine **5.4.4**.
- Файл проекта `obstacle_course.uproject`.
- Python-скрипт для генерации окружения, если требуется повторная генерация декора.

### Запуск проекта

1. Откройте `obstacle_course.uproject` в Unreal Engine 5.4.4.
2. Дождитесь загрузки проекта и необходимых ресурсов.
3. Откройте карту `Content/ObstacleCourse/Maps/LV_MainMenu`.
4. Нажмите **Play**, чтобы запустить игру.

Карта главного меню — `LV_MainMenu`.

Основной игровой уровень — `Content/ObstacleCourse/Maps/LV_Canyon`.

Для генерации декора вдоль сплайна каньона используется редакторский Python-скрипт `Content/Python/generate_canyon.py`. Скрипт предназначен для размещения сосен, валунов и скал вдоль маршрута. Повторная генерация может потребоваться при изменении геометрии или параметров сплайна.

## Карты и игровой цикл

| Карта | GameMode | Назначение |
| --- | --- | --- |
| `LV_MainMenu` | `BP_MainMenuGameMode` | Главное меню, настройки сложности и запуск игры |
| `LV_Canyon` | `BP_ObstacleCourseGameMode` | Основной игровой процесс |

### Игровой цикл

1. Игрок запускает игру и попадает в главное меню.
2. В разделе Settings можно выбрать уровень урона от падающих камней.
3. При выборе Start Game загружается `LV_Canyon`.
4. Во время прохождения игрок собирает монеты, уклоняется от препятствий и восстанавливает здоровье.
5. При гибели персонажа отображается экран смерти.
6. Во время игрового процесса нажатие Escape открывает меню паузы.

Настройки матча хранятся в `BP_ObstacleCourseGameInstance`. Параметр `Rock Damage` определяет урон от падающих камней и может принимать следующие значения:

- `10` — низкий урон;
- `25` — средний урон;
- `50` — высокий урон.

Спавнер падающих камней получает текущее значение через `GetRockDamage`.

## Управление

Для обработки пользовательского ввода используется Enhanced Input и контекст `IMC_ObstacleCourse`.

| Действие | Input Action | Управление |
| --- | --- | --- |
| Движение персонажа | `IA_ObstacleCourseMove` | WASD |
| Обзор | `IA_ObstacleCourseLook` | Мышь |
| Прыжок | `IA_ObstacleCourseJump` | Space |
| Пауза | `IA_ObstacleCoursePauseMenu` | Escape |

### Персонаж и обработка ввода

Основной класс персонажа — `BP_ObstacleCourseCharacter`. Он использует камеру от третьего лица и поворот тела в соответствии с направлением движения.

`BP_ObstacleCoursePlayerController` обрабатывает движение и обзор. Логика прыжка реализована непосредственно в классе персонажа.

## Игровые механики

### Здоровье и смерть

Система здоровья реализована в компоненте `BP_HealthComponent`, который подключается к персонажу. Компонент отвечает за:

- хранение текущего и максимального здоровья (`Health` и `DefaultHealth`);
- обработку урона через событие `OnTakeAnyDamage`;
- уведомление о получении урона через `OnOwnerDamaged`;
- уведомление о смерти через `OnOwnerDied`.

При попадании камня камера игрока трясётся с использованием `CS_PlayerRockHit`.

При смерти персонажа активируется ragdoll: для физической симуляции используется `SetSimulatePhysics`. Управление персонажем отключается, а HUD отображает `WBP_DeathScreen`.

### Монеты

Сбор монет реализован в `BP_Coin`.

- Монета вращается на месте.
- **Magnetic Zone** притягивает монету к игроку.
- **Pick Up Zone** инициирует подбор монеты.
- При подборе проигрываются анимация сжатия, звук и визуальные эффекты.
- Количество монет игрока увеличивается через `EarnPlayerCoins` в Player State.
- После подбора актор монеты уничтожается.

Собранные монеты используются для восстановления здоровья.

### Лечение

Для взаимодействия с системой лечения используется Blueprint Interface `BPI_HealthHandler` с методом `TryHealingByCoins`. Лечение требует оплаты монетами. Стоимость задаётся параметром `Price`.

`BP_HealingSphere` реализует лечебную сферу:

1. Когда игрок входит в сферу, запускается периодическое выполнение лечения через таймер.
2. При выполнении условий лечения игрок восстанавливает здоровье за монеты.
3. Во время лечения проигрываются визуальные эффекты в виде крестов и звук медитации.
4. При выходе игрока из сферы latent-объект `BPW_DeactivateHealing` отключает соответствующий эффект.

### Падающие камни

Механика камней состоит из трёх основных Blueprint-классов.

#### `BP_Rock`

Физический камень, который при столкновении с игроком наносит урон. При ударе воспроизводятся звук столкновения и эффект пыли.

#### `BP_FallingRock`

Зона предупреждения о падении камня. Она отвечает за визуальное и звуковое сопровождение события:

- показывает VFX-индикацию места падения камня;
- проигрывает звук полёта;
- создаёт экземпляр `BP_Rock` со смещением по высоте.

#### `BP_FallingRockSpawner`

Спавнер автоматически активируется, когда игрок приближается на расстояние меньше `Activation Distance`.

После активации спавнер периодически выбирает позицию впереди или сбоку от игрока. Для выбора позиции используются параметры:

- `Forward Distance Range`;
- `Right Distance Range`.

Перед созданием новой зоны проверяется минимальное расстояние до ранее использованных точек. Это позволяет уменьшить вероятность появления камней слишком близко друг к другу.

Урон от падающих камней определяется настройкой `Rock Damage`, хранящейся в `BP_ObstacleCourseGameInstance`.

### Смертельная зона

`BP_DeathZone` реализует область, нахождение в которой приводит к периодическому получению урона персонажем. Пока игрок находится внутри зоны, периодически наносится урон через таймер.

Дополнительные эффекты:

- звук сердцебиения;
- красный post-process, усиливающий ощущение опасности.

При выходе игрока из зоны таймер и звук останавливаются.

### Движущиеся платформы

`BP_MovingPlatform` реализует движение платформы. Движение управляется Timeline `MoveCycle`.

При входе игрока в триггер платформы может временно увеличиваться скорость передвижения персонажа. Для настройки используются параметры:

- `Default Speed` — обычная скорость;
- `Boost Speed` — скорость во время ускорения;
- `Boost Duration` — продолжительность ускорения.

Столкновение с платформой также может наносить урон.

### Окружение и генерация декора

#### `BP_CanyonPath`

Актор, содержащий сплайн маршрута каньона. Сплайн используется Python-скриптом для размещения объектов окружения вдоль игрового маршрута. Основная игровая логика в самом акторе практически отсутствует.

Для генерации используются сосны, валуны и скалы. Скрипт генерации: `Content/Python/generate_canyon.py`.

#### `BP_CustomizableSign`

Актор таблички с настраиваемым текстом. Позволяет размещать в игровом мире таблички с различными надписями.

## Пользовательский интерфейс

Интерфейс построен на UMG и Blueprint Widgets. Визуальный стиль включает декоративные плашки, маски прогресс-бара, элементы отображения монет и шрифт Bangers.

Для стандартных кнопок используется `WBP_RegularButton`, поддерживающий звуковые эффекты наведения и нажатия.

### Главное меню

Главное меню реализовано в `WBP_MainMenu`. Виджет создаётся через `BP_MainMenuPlayerController`. Для взаимодействия с интерфейсом используется режим ввода UI Only с включённым курсором.

Для переключения между разделами используется `WidgetSwitcher`. Доступны следующие разделы:

- **Start Game** — переход на игровую карту `LV_Canyon`.
- **Settings** — выбор урона от камней.
- **Credits** — отображение информации об авторах.
- **Quit** — выход из игры.

Кнопки Back возвращают игрока на основной экран меню.

#### Настройки

В разделе Settings расположен `ComboBox_RockDamage` с подписью `Rock damage:`. Доступные значения: `10`, `25` и `50`.

Выбранное значение сохраняется в `BP_ObstacleCourseGameInstance` и используется спавнером падающих камней. Строки выпадающего списка отображаются через `WBP_ListRow`.

### HUD

Игровой интерфейс реализован в `WBP_PlayerInterface` и создаётся через `BP_ObstacleCourseHUD`. HUD отображает:

- **Здоровье** — текущее и максимальное количество HP персонажа.
- **Монеты** — количество монет, собранных игроком.

Для отображения состояния используются UMG bindings.

### Меню паузы

Меню паузы реализовано в `WBP_PauseMenu`. При нажатии Escape контроллер ставит игру на паузу с помощью `Set Game Paused`, включает курсор и отображает меню.

- **Resume** — закрыть меню паузы, снять паузу и вернуть режим ввода Game Only.
- **Main Menu** — перейти на `LV_MainMenu`.
- **Quit** — выйти из игры.

### Экран смерти

Экран смерти реализован в `WBP_DeathScreen`. `BP_ObstacleCourseHUD` подписывается на событие `OnOwnerDied` персонажа. При смерти игровой HUD скрывается и отображается экран смерти.

В текущей версии экран смерти предназначен для отображения состояния гибели персонажа. Возможность начать забег заново или вернуться в главное меню входит в планы дальнейшей разработки.

## Архитектура проекта

Основные системы проекта разделены по ответственности.

| Система | Основные классы | Ответственность |
| --- | --- | --- |
| Персонаж | `BP_ObstacleCourseCharacter` | Перемещение и прыжок |
| Управление | `BP_ObstacleCoursePlayerController` | Обработка ввода и управления |
| Игровой режим | `BP_MainMenuGameMode`, `BP_ObstacleCourseGameMode` | Поведение игры на соответствующих картах |
| Игровое состояние | `BP_ObstacleCourseGameState` | Состояние игрового процесса |
| Состояние игрока | `BP_ObstacleCoursePlayerState` | Данные игрока, включая монеты |
| Настройки игры | `BP_ObstacleCourseGameInstance` | Настройки, сохраняющиеся при переходах между картами |
| Здоровье | `BP_HealthComponent`, `BPI_HealthHandler` | Получение урона, смерть и взаимодействие с лечением |
| Игровые объекты | `BP_Coin`, `BP_HealingSphere`, `BP_Rock` | Монеты, лечение и взаимодействие с камнями |
| Препятствия | `BP_FallingRock`, `BP_FallingRockSpawner`, `BP_DeathZone`, `BP_MovingPlatform` | Опасности и интерактивные элементы уровня |
| Интерфейс | `WBP_MainMenu`, `WBP_PlayerInterface`, `WBP_PauseMenu`, `WBP_DeathScreen` | Главное меню, HUD, пауза и экран смерти |
| Генерация окружения | `BP_CanyonPath`, `generate_canyon.py` | Сплайн маршрута и размещение декора |
